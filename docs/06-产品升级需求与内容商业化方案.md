# 梦见小程序产品升级需求与内容商业化方案

**版本**：v1.0

**状态**：讨论结论版

**适用范围**：前端信息架构、首页/发现/记梦/我的页面升级，塔罗、心理测试和心灵书店首版规划。

## 一、升级目标

本次升级采用新的视觉和内容方向，但保留现有梦境记录、AI 解析、任务、积分、会员和探索广场能力。

产品从单一的“梦境记录工具”扩展为“梦境记录 + 自我探索内容”的应用，新增塔罗、心理测试和书籍推荐入口。书籍首版只验证内容兴趣，不接商城、支付和订单。

## 二、已确定的产品决策

### 2.1 底部导航保留 4 个 Tab

| Tab  | 主要职责                                 |
| ---- | ---------------------------------------- |
| 首页 | 记梦入口、最近梦境、任务和快捷功能       |
| 发现 | 探索广场、塔罗、心理测试、心灵书店       |
| 记梦 | 创建和编辑梦境、开始解析                 |
| 我的 | 打卡、日历、积分、会员、成就、设置和书架 |

不新增第五个底部 Tab。塔罗、心理测试和书店作为“发现”页的内容入口，避免隐藏或移除已有探索广场。

### 2.2 书籍先做静态推荐

首版只提供书籍展示、分类筛选、推荐理由和收藏能力，不包含：

- 在线支付
- 订单和退款
- 库存与发货
- 商城账户绑定
- 第三方商城跳转
- 书籍推荐的后端持久化

## 四、页面升级需求

### 4.1 首页

采用设计稿的轻量视觉，但保留现有业务模块。

#### 页面结构

1. 紫色渐变头部和问候语。
2. 圆形“记梦”主按钮。
3. 四个快捷卡片：今日塔罗、心理测试、梦境打卡、探索广场。
4. 最近的梦。
5. 今日小任务。
6. 底部 4 个 Tab。

#### 现有能力保留

- 连续记梦天数
- 最近梦境轮播或详情卡片
- 今日任务和积分奖励
- 梦境详情入口
- 暗黑模式

连续记梦天数合并进“梦境打卡”卡片，避免顶部出现过多独立徽章。

### 4.2 发现页

发现页默认打开探索广场，保证现有公开梦境、点赞和用户主页功能仍然是主要内容。

#### 页面结构

1. “发现”头部区域。
2. 三个快捷入口：塔罗、心理测试、心灵书店。
3. 内容分类切换：梦境、塔罗、测试、书店。
4. 默认展示探索广场的信息流。

塔罗、心理测试和书店可以使用横向分类标签或卡片入口，不占用新的底部 Tab。

### 4.3 记梦页

采用“简化表面、保留完整能力”的方式。

#### 首屏内容

- 梦境输入框
- 字数统计和 25～1000 字校验
- 常用梦境元素标签
- 开始解析按钮

#### 版本与记录设置

首版将高频设置放在输入区附近，减少隐藏入口带来的理解成本：

- AI 润色
- 版本切换
- 自定义标签
- 情绪选择
- 公开/私密设置

润色先以静态示例预览，用户明确应用后才生成润色版本；原始版本始终保留。编辑页不放“查看版本历史”按钮，版本比较、复制和切换集中在详情页进入的独立版本页。

编辑已有梦境时继续支持“仅保存”和“保存并重新解析”。首版不能因为对齐设计稿而删除这些能力。

### 4.4 我的页

将设计稿的打卡结构与当前个人中心能力合并。

#### 页面结构

1. “我的 / 你的潜意识档案”头部。
2. 梦境打卡卡片，显示今日是否记录。
3. 记梦总数、本月打卡、连续打卡。
4. 梦境日历。
5. 会员中心、幸运值、成就、设置。
6. 我的书架入口。

以下现有功能不得移除：

- 头像和用户资料
- VIP/权益状态
- 幸运值
- 成就
- 设置、隐私和数据导出

## 五、新增内容模块

### 5.1 塔罗

首版只做前端体验：

- 每日一牌
- 三牌阵
- 点击翻牌
- 静态牌面和解释文案
- 当次结果展示

首版暂不保存塔罗历史，也不新增后端接口。后续若验证有使用量，再增加历史记录和个性化推荐。

### 5.2 心理测试

首版包含：

- MBTI 8 道题
- 大五人格 5 道题
- 答题进度
- 结果页
- 重新测试

首版结果可以只保存在当前设备，不新增用户结果表。结果页可以链接到相关梦境主题和书籍分类。

### 5.3 心灵书店

首版是静态内容页，支持：

- 分类筛选
- 书籍卡片
- 书名、作者、简介
- 推荐理由
- 价格展示
- “即将上架”状态
- 收藏书籍

首版不提供购买按钮，避免在没有真实交易链路时制造错误预期。

## 六、书籍推荐规则

### 6.1 推荐出现位置

首版只放两个位置：

1. **梦境解析结果页**：在解析内容、运势和今日任务之后，展示“延伸阅读”，推荐 1～2 本书。
2. **发现页心灵书店**：展示完整书单，支持分类筛选。

暂不放在记录页。用户还没有完成梦境输入时，推荐缺乏上下文；首页也暂时不增加独立书籍模块，避免影响记梦主路径。

### 6.2 推荐匹配

首版使用可解释的标签匹配，不使用复杂 AI 推荐：

| 梦境或解析主题   | 推荐方向               |
| ---------------- | ---------------------- |
| 考试、追逐、迷路 | 压力、焦虑、控制感     |
| 亲人、家庭、争吵 | 关系、原生家庭、沟通   |
| 飞行、水、死亡   | 潜意识、象征、荣格     |
| 塔罗结果         | 自我探索、成长、心理学 |
| MBTI 结果        | 人格、自我理解、沟通   |

没有匹配结果时展示通用热门书单。

### 6.3 书籍卡片

每张卡片包含：

- 书名
- 作者
- 分类标签
- 简短简介
- 推荐理由
- 价格展示
- 收藏按钮
- 上架状态

推荐理由必须说明和用户内容的关联，例如：

> 你的梦境出现了“迷路”和“考试”，这本书适合了解压力和自我期待。

推荐文案不得暗示医疗诊断、治疗效果或确定性的命运结论。

## 七、商业化路线

### 7.1 阶段一：内容验证

目标是验证用户是否愿意浏览和收藏书籍。

- 使用静态书籍数据
- 只做分类、详情和收藏
- 记录页面浏览和收藏情况时，优先复用现有统计能力
- 不接商城和支付

### 7.2 阶段二：联盟导购

如果书籍点击和收藏数据达到预期，再考虑接入第三方商城或小程序，采用 CPS/佣金模式。

优势：

- 不需要库存
- 不需要自行发货
- 不需要承担售后
- 可以较快验证成交转化

需要提前确认微信小程序对第三方小程序跳转、`web-view` 和外部链接的限制。

### 7.3 阶段三：内容合作

在有稳定流量和购买数据后，再考虑：

- 出版社或书店合作书单
- 专题优惠券
- 联名活动
- 电子书、课程或音频内容

首版不建设自营商城。自营商城会引入商品、库存、支付、订单、退款、发货和客服等完整业务链路，当前需求没有足够依据支持这项投入。

### 7.4 商业和内容边界

- 商业合作或佣金推荐需要明确标识。
- 书籍封面和介绍需要确认版权来源。
- 不以心理治疗、疾病诊断或保证效果作为推荐卖点。
- 书籍推荐应服务于梦境和自我探索主流程，不应打断记录和解析。

## 八、数据和技术范围

### 8.1 本期不新增后端模块

塔罗、心理测试和书店首版使用前端静态数据，不新增数据库表和后端 API。

书籍数据可以先放在前端独立数据文件中，避免把大量内容写进页面模板。

### 8.2 现有后端能力继续复用

- 梦境创建、编辑和删除
- AI 解析和重新解析
- 梦境版本管理
- 梦境日历
- 任务和积分
- 会员权益
- 探索广场和点赞
- 用户资料和设置

### 8.3 后续可能新增的接口

只有在验证需求后再考虑：

- 塔罗历史
- 心理测试结果同步
- 书籍收藏同步
- 书籍点击和转化统计
- 第三方商城跳转和订单回流

## 九、实施顺序

### 第一阶段：信息架构和视觉融合

- 固定 4 个 Tab
- 调整首页
- 调整发现页入口
- 调整记梦页首屏
- 调整我的页
- 保留现有业务能力

### 第二阶段：新增内容体验

- 塔罗静态 MVP
- 心理测试静态 MVP
- 心灵书店静态 MVP
- 解析结果页增加延伸阅读

### 第三阶段：数据验证

- 观察书籍浏览、收藏和返回率
- 观察塔罗和测试使用率
- 评估是否需要结果同步和推荐优化

### 第四阶段：商业化接入

只有在数据证明用户有明确购买意愿后，再评估联盟导购或内容合作。

## 十、验收标准

- 底部导航仍为 4 个 Tab，探索广场可直接进入。
- 首页能直接进入记梦、塔罗、心理测试和探索。
- 记梦页保留 25～1000 字校验和现有高级能力。
- 我的页同时具备打卡、日历、积分/会员、成就和设置入口。
- 解析结果页能展示与梦境主题相关的静态书籍推荐。
- 心灵书店支持分类浏览和收藏，不出现不可用的支付流程。
- 塔罗和心理测试可以完成首版交互，不依赖后端接口。
- 书籍推荐文案不会产生医疗或确定性命运承诺。

## 十一、暂不纳入范围

- 五 Tab 导航
- 自营商城
- 库存、订单、支付和退款
- 塔罗和测试的服务端历史
- AI 自动生成书籍推荐
- 复杂推荐算法
- 书籍广告投放和付费置顶
